# Cara
Developed a responsive e-commerce shopping website named **Cara**, designed to provide users with a smooth and convenient online shopping experience. The website features multiple sections, including Home, Shop, Blog, About, Contact, and Shopping Cart.

The Home page showcases featured products, new arrivals, promotional offers, discounts, and shopping highlights. The Shop page displays product listings with images, brand names, prices, and shopping cart options. The Shopping Cart page allows users to view selected products, manage quantities, check product subtotals, apply coupon codes, and calculate the overall order total, including shipping charges.

The website also includes newsletter subscription and customer information sections to improve user engagement. The project focuses on creating an attractive user interface, organized product presentation, and easy navigation across different pages.

**Key Features:**
- Responsive e-commerce website layout
- Product listing and display
- Shopping cart interface
- Quantity and price management
- Coupon application section
- Order summary and checkout interface
- Multiple interconnected website pages
